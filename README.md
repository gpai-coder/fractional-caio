# Fractional CAIO — Ganesh Pai

Marketing site for Ganesh Pai’s Fractional Chief AI Officer advisory practice.

## Edit copy

All site copy lives in **`src/content.ts`**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy (Vercel)

1. Import [gpai-coder/fractional-caio](https://github.com/gpai-coder/fractional-caio) in the Vercel dashboard (team **gpai1**, Hobby).
2. Framework preset: **Next.js** (zero-config).
3. Optional: set `NEXT_PUBLIC_SITE_URL` to your production URL for canonical and Open Graph links.

## Stack

Next.js 15 (App Router), TypeScript, Tailwind CSS 4.
